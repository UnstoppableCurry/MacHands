# 交给浏览器助手执行的作业(总目录)

这份文档给**自动化浏览器助手**执行。它能开网页、填表、注册账号、在各种后台点按钮，但它对本项目一无所知，也看不到我们的代码和服务器。

每份子文档都是**独立作业**，可以单独派给一个执行者，不需要读别的文档。

## 0. 你在为什么项目干活(一段话看完)

**MacHands** 是一个 macOS 菜单栏 App，让云端的 AI 助手在用户自己的 Mac 上干活：执行命令、读写文件、截屏录屏、控制键鼠。数据端到端加密，中转服务器只看得到密文。

它**不上 Mac App Store**——App Store 要求应用跑在沙盒里，而沙盒恰好禁止上面这些能力。所以只走**官网下载**。

- 卖法：**49 美元买断，含一年更新，内置 7 天试用**。
- 许可证是自研的：买家付款后，我们的服务器签发一串 `MHL1.…` 的字符串发到买家邮箱，买家粘进 App 的设置窗口。
- 所以收款渠道**只需要两件事**：能收款、能在收款成功后发一个 webhook 通知我们。它自带的许可证系统我们用不上。

## 2. 全局禁止事项(每份作业都适用)

违反任何一条就**停下来交回给人**，不要自作主张。

1. **不许花钱**，除了作业里明确写出的"域名注册费"和"渠道账号本身的订阅费"。任何加购、增值服务、隐私保护以外的附加项、更长年限的预付，一律不买。看到"推荐搭配""限时优惠"就跳过。
2. **不许把密钥、API key、密码、webhook 签名密钥贴进聊天记录**，也不要贴进任何在线文档、截图、issue、代码仓库。拿到之后按每份作业末尾说的"安全交接"办法处理。
3. **不许改动已有的 Apple 证书**。作业 4 只看不动：不新建、不撤销(revoke)、不下载、不删除任何证书或描述文件。
4. **遇到要身份证件、护照、银行卡号、人脸识别、活体检测、手持证件照的步骤，立刻停下**，把停在哪一步、页面要什么，写清楚交回给人。不要代填，不要上传任何证件。
5. **不许注册与本作业无关的账号**，不许把老板的邮箱订阅到营销列表（能取消勾选就取消）。
6. **两步验证**：如果某个网站要求短信/邮箱验证码或 TOTP，把页面停在那里交回给人，不要试图绕过。
7. 遇到与本文档描述不符的页面（改版了、入口换了名字），**按含义找相近的入口**，并在回填表里写下"实际路径是什么"，不要编造一个不存在的按钮名当作已完成。

## 4. 关于我们服务器的固定信息

写进各家后台时会用到：

- 服务器公网 IP：`134.199.230.126`
- webhook 接收地址：`https://<域名>/api/store/webhook/<渠道名>`
  （`<渠道名>` 是全小写的 `lemonsqueezy`、`paddle` 或 `creem` 三者之一，取决于最终选哪家）
- 网站首页：作业 1 完成前是 `http://134.199.230.126/`，完成后是 `https://<域名>/`
- 建议的发件地址：`license@<域名>`

**注意**：域名解析生效后，网站在我们装好 TLS 证书之前**只有 http 能打开**。如果最终域名是 `.app` 或 `.dev` 结尾，浏览器会强制 https，于是**网站会暂时打不开**——这是预期内的，不是你做错了。照常把回填表交上来，装证书是我们这边的事。
