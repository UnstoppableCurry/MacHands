Give your cloud AI agent a pair of hands on your Mac.

装好之后怎么开始 Getting started

  • 把 MacHands.app 拖进「应用程序」,双击打开。菜单栏会出现一只手。 Drag MacHands.app into Applications and open it. A hand appears in the menu bar.
  • 点菜单里的 复制给 agent,把那段文字贴给你的云端 agent。 Click Copy for agent and paste the block into your cloud agent.
  • 配对成功后会弹出授权页:选一次范围,点「授权并验证」。之后不再打扰。 Once paired, pick an access scope once and hit Authorize & verify. It won't ask again.
从源码打出来的未签名包,第一次打开请右键 → 打开。
GitHub Releases 上出现经公证的签名包之后,双击即可。 Unsigned source builds: right-click → Open. A notarized GitHub Release, once published, can be opened with a double-click.

它会问你三项系统权限 Three system permissions

  • 通知 — 命令跑完、需要你决定时,能提醒你一声。 Notifications — so the agent can tell you a job finished or needs you.
  • 屏幕录制 — 代理要截屏或录屏给你看结果时用。 Screen Recording — for screenshots and screen recordings.
  • 辅助功能 — 代理要动键盘鼠标(点按钮、试手感)时用。 Accessibility — for keyboard and mouse control.

三项都可以随时在「系统设置 → 隐私与安全性」里收回;不给也能用,只是对应的能力不可用。 All three are revocable in System Settings → Privacy & Security. MacHands still works without them, minus those abilities.

升级由 App 自己完成 Updates are built in

签名包发布之后,MacHands 会自己检查新版本、验证签名、原地替换并重启。 升级后不需要重新授权系统权限。现在还没有 Release 附件时,请从仓库重新构建。

After a signed build is published, MacHands can update itself in place — system permissions survive. Until a GitHub Release asset exists, rebuild from this repo.
