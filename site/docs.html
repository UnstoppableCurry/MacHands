配对:三步Pairing: three steps

在 Mac 上点「复制给 agent」Click "Copy for agent" on the Mac

菜单栏那只手 → 复制给 agent。配对码 10 分钟有效,只能用一次。The hand in the menu bar → Copy for agent. The code is valid for ten minutes and single-use.

贴给 agent,让它自己跑Paste it to the agent

复制到的内容里就有下面这行。The copied block already contains this line.

npx -y machands pair "MH1…"

在 Mac 上选一次授权范围Pick a scope on the Mac

窗口会自己弹出来。点一下就生效,自检自己跑完。The window opens by itself. Your click applies immediately and the self-check runs.

配成之后可以设个默认 Mac,后面就不用每条都写 --mac: Set a default Mac afterwards so you don't repeat --mac every time:

machands use "我的 Mac mini"

三种授权范围The three scopes

在窗口里点一下就换,也可以从菜单栏那只手 → 模式 换。危险命令黑名单在三种范围下都生效,包括开发者。 Switch with one click in the window, or from the hand in the menu bar → Mode. The denylist applies in all three, including Developer.

开发者Developer

全部放行,不弹卡。适合你信任这个 agent、要它连续干活的时候。Everything allowed, no cards. For when you trust the agent and want it working continuously.

只读Read-only

只能看不能改:截屏、读文件、查状态可以;执行命令、写文件、动键鼠一律拒绝。Look, don't touch: screenshots, reading files and status are fine; commands, writes and input are refused.

逐条审批Ask

每条都弹卡等你点:允许一次 / 允许 1 小时 / 总是允许这条 / 拒绝。Every command waits for a card: allow once / for an hour / always this one / refuse.

切到只读或逐条审批之后,agent 自己没法把模式改回去 —— 改模式这件事本身也要经过审批。这是有意的:只有坐在 Mac 前的人能放开。 Once you switch to Read-only or Ask, the agent cannot switch back on its own — changing the mode is itself gated. That's deliberate: only the person at the Mac can loosen it.

写清楚你要干什么:--whySay what you're after: --why

会弹审批卡的命令都接 --why。Mac 前的人看到的是这句人话,不是命令本身;命令原文折在「详情」里。 Every command that can raise a card takes --why. The person at the Mac reads that sentence, not the command; the raw line sits behind a details toggle.

好Good

--why "确认雪场地形改完之后的样子"

说的是目的。人一眼能判断该不该批。States the goal. A human can decide at a glance.

坏Bad

--why "运行 screencapture"

只是把命令换个说法,等于没说。Just restates the command. Says nothing.

许可证License

付款后你会收到一串以 MHL1. 开头的字符。在 Mac 上打开菜单栏那只手 → 设置,把它粘进许可证输入框,回车。试用提示立刻消失,不用重启。 After payment you receive a string starting with MHL1.. On the Mac open the hand in the menu bar → Settings, paste it into the license field and press return. The trial notice disappears immediately; no restart.

试用是 7 天。到期后只有「执行命令」和「写文件」被拦下,其余照常。 The trial runs 7 days. When it lapses only "run a command" and "write a file" stop; everything else keeps working.

出问题先看这三处When something's off, look here

1 · machands doctor

一条命令说清:中继通不通、Mac 在不在线、App 什么版本、签名是谁、三项权限给没给、是不是装了好几份 MacHands。装了多份会互相抢身份,表现成"时灵时不灵、方法找不到" —— 这是最常见的坑。One command covers it: relay reachable, Mac online, app version, who signed it, the three permissions, and whether several copies of MacHands are installed. Duplicates fight over the same identity and look like "works sometimes, method not found" — the most common trap.

2 · machands verify

七项挨个跑一遍:执行命令、读写文件、截屏、键鼠、通知、后台作业、MCP 桥。没过的那项后面直接写着该去哪儿修。Runs all seven: commands, files, screenshot, input, notification, background job, MCP bridge. Each failure prints where to go and fix it.

3 · 审计日志The audit log

每一条请求、你的决定、执行结果都在这里,人话摘要和命令原文都有:Every request, your decision and the outcome, with both the plain-language summary and the raw command:

~/Library/Logs/MacHands/audit.log

几个常见现象A few common symptoms

命令被拒绝,但我没点拒绝Refused, but nobody clicked refuse
多半是模式在只读,或者整个暂停了。看菜单栏那只手 → 模式。危险命令黑名单也会直接拒,那种情况提示里会写出命中的是哪一条。Usually the mode is Read-only, or everything is paused. Check the hand in the menu bar → Mode. The denylist also refuses outright — then the message names the rule it hit.
截屏失败,说没有权限Screenshots fail with a permission error
在 Mac 上打开「系统设置 → 隐私与安全性 → 屏幕录制」勾上 MacHands。想看 MacHands 自己的界面则不需要这个权限,用 machands selfshot。Tick MacHands in System Settings → Privacy & Security → Screen Recording. To look at MacHands' own window you don't need it at all — use machands selfshot.
提示某个方法不存在It says a method doesn't exist
Mac 上的 App 比 npm 包旧。跑 machands update 让它自己升级,或者在 Mac 上从菜单栏检查更新。The app on the Mac is older than the npm package. Run machands update, or check for updates from the menu bar on the Mac.
连不上,说中继断了It can't reach the relay
同一个 agent 身份同时开两个连接会互相顶下线。确认没有第二个会话在用同一份配置,再跑 machands doctor。Two connections sharing one agent identity kick each other off. Make sure a second session isn't using the same config, then run machands doctor.
