## 目标

只做三件事：查出 **Developer ID 证书的到期日**、**开发者账号年费的到期日**、以及**用于软件公证的"App 专用密码"是否还存在**。

## ⚠️ 这份作业只看不动

**绝对不许**：新建证书、撤销（Revoke）证书、下载证书、删除描述文件（Provisioning Profile）、删除或重新生成 App 专用密码、修改任何账号设置。

原因：这个证书是给已经在售的软件签名用的。撤销它会让**所有已经卖出去的软件在用户电脑上失效**。这是不可逆的。

看到任何"Revoke""Delete""Regenerate""Revoke and Regenerate"按钮，**绕开它**。

## 前置条件

- 老板的 Apple ID 与密码。
- Apple 一定会要**双重认证验证码**（发到老板的其他苹果设备上）。到这一步就**停下来交回给人**，等老板把码给你，或者由老板本人登录后把页面交给你。

## 第一件：Developer ID 证书到期日

1. 打开 `https://developer.apple.com/account`，登录。
2. 进入 **Certificates, Identifiers & Profiles**（证书、标识符和描述文件）。
3. 左侧选 **Certificates**。
4. 在列表里找**类型为 `Developer ID Application`** 的那一条。
   - 我们的团队 ID 是 `3PW7WV39F5`，如果账号下有多个团队，先在右上角切到这个团队。
   - 列表里可能同时有 `Apple Development`、`Apple Distribution`、`3rd Party Mac Developer` 等其他类型，**我们只关心 `Developer ID Application`**。
5. 记下它的 **Expiration Date（到期日）** 和名称。
   - 如果有**多条** `Developer ID Application`，把每一条的名称和到期日都记下来。
6. **看完就走，不要点进去下载，不要点任何 Revoke。**

## 第二件：账号年费到期日

1. 还在 `https://developer.apple.com/account`。
2. 找 **Membership** / **Membership details**（会员详情）入口。
3. 记下 **Expiration Date** 或"下次续费日期"。
4. 顺便记下 **Team ID**，确认是不是 `3PW7WV39F5`。

## 第三件：App 专用密码是否还存在

这个密码是给"软件公证"用的，存在老板 Mac 的钥匙串里，我们需要知道它有没有被删掉。

1. 打开 `https://account.apple.com`（旧地址 `appleid.apple.com` 会跳转过去），用同一个 Apple ID 登录。
2. 找 **登录与安全 / Sign-In and Security** → **App 专用密码 / App-Specific Passwords**。
3. 记下**列表里有几条、每条的标签叫什么**（我们这条的标签可能含 `notary`、`machands` 或类似字样）。

**重要的实话**：这个页面**只能看到密码的标签，看不到密码本身**，也**无法验证它还能不能用**。所以你只需要回答"**它还在不在**"。真正能不能用，要在老板的 Mac 上实际跑一次公证才知道——那不是你的活。

**不要删除、不要重新生成任何一条。**
